# Contributing

Contributions welcome! Please make sure your pull request adheres to the
[awesome-lists guidelines](https://github.com/sindresorhus/awesome/blob/main/pull_request_template.md):

- Keep a sensible order within each section: alphabetical, chronological
  or numeric, whichever fits the material.
- One link per line, with a short, clear description.
- No duplicate entries.
- Check that the link works before submitting.
